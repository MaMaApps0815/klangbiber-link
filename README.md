# klangbiber-link

Weiterleitungsseite fuer die App **Klangbiber**. Erkennt das Geraet und oeffnet
den App Store (iPhone, iPad) beziehungsweise Google Play (Android). Rechner und
unbekannte Geraete sehen beide Schaltflaechen.

* `index.html` - die Seite, ohne Abhaengigkeiten
* `vorschau.png` - Vorschaubild fuer WhatsApp und soziale Netze (1200x630)
* `schriften/` - Fraunces und Outfit, selbst gehostet statt ueber Google Fonts

Mit `?bleib` am Ende der Adresse bleibt die Seite stehen, statt weiterzuleiten.

Gehostet ueber GitHub Pages.
